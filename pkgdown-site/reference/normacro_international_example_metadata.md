# Metadata for det internasjonale NorMacro-eksempeldatasettet

Metadata for variablene i \[normacro_international_example\], med én rad
per økonomisk variabel. Kolonnene \`Aar\` og \`Land\` har ikke egne
metadata-rader.

## Usage

``` r
normacro_international_example_metadata
```

## Format

En tibble med 12 observasjoner og 16 variabler:

- Variabel:

  Internt variabelnavn i NorMacro.

- Display_navn:

  Visningsnavn for variabelen.

- Type:

  Om serien er original eller beregnet.

- Kategori:

  Tematisk kategori.

- Beskrivelse:

  Kort beskrivelse av variabelen.

- Kilde:

  Datakilde.

- Kilde_url:

  URL til datakilden når tilgjengelig.

- Tabell:

  Kildetabell eller underliggende variabel.

- Enhet:

  Måleenhet.

- Frekvens:

  Datafrekvens.

- Startaar:

  Første år serien er tilgjengelig.

- Sluttaar:

  Siste år dersom serien har avsluttet dekning.

- Funksjon:

  NorMacro-funksjonen som henter eller beregner serien.

- Kommentar:

  Supplerende informasjon om serien.

- Omraade:

  Geografisk område.

- Analyse_type:

  Variabelens analysetype, for eksempel nivå, rate eller indeks.

## Source

Metadata fra NorMacro.

## Details

Metadataene inneholder blant annet visningsnavn, variabeltype, kategori,
beskrivelse, kilde, enhet, frekvens og analysetype.
