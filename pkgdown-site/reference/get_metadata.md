# Hent metadata for et NorMacro-datasett

Returnerer metadata som passer til datasettet som oppgis. Dersom
\`data\` ikke oppgis, returneres metadata for de norske makrodataene.

## Usage

``` r
get_metadata(data = NULL)
```

## Arguments

- data:

  Valgfritt NorMacro-datasett. Datastrukturen brukes til å identifisere
  riktig metadataområde.

## Value

En tibble med metadata for variablene i datasettet.
