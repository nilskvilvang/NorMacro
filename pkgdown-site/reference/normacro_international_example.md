# Internasjonalt eksempeldatasett fra NorMacro

Et lite, statisk utsnitt av NorMacros internasjonale makrodatasett for
Norge, Sverige, Danmark, Finland, Tyskland og Frankrike i perioden
2000–2025.

## Usage

``` r
normacro_international_example
```

## Format

En data.frame med 156 observasjoner og 14 variabler:

- Aar:

  År.

- Land:

  Landkode.

- HICP:

  Harmonisert konsumprisindeks.

- Inflasjon:

  Årlig inflasjon.

- Befolkning:

  Befolkning.

- Arbeidsledighetsrate:

  Arbeidsledighetsrate.

- BNP_faste_priser:

  BNP i faste priser.

- BNP_vekst:

  Årlig BNP-vekst.

- Sysselsatte:

  Sysselsatte personer.

- Arbeidsstyrke:

  Personer i arbeidsstyrken.

- Boligprisindeks:

  Boligprisindeks.

- Boligprisvekst:

  Årlig vekst i boligprisindeksen.

- Eksport:

  Eksport av varer og tjenester.

- Import:

  Import av varer og tjenester.

## Source

NorMacro. Dataene er et statisk utsnitt av data hentet og bearbeidet av
pakkens ordinære internasjonale datainnhentingsfunksjoner.

## Details

Datasettet er laget for bruk i eksempler, vignetter og dokumentasjon,
slik at disse kan kjøres uten å hente data fra eksterne API-er.
